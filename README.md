# Практическая работа №6 — Альбомы и их авторы (API)

**Автор:** Харланович Алексей, ПИУКИС-23

## Описание
Приложение для работы с API JSONPlaceholder. Позволяет просматривать список альбомов, информацию об авторе и сетку фотографий альбома. Выполнено на чистом JavaScript (ES6+).

## Что реализовано (все 8 заданий)
1. **Список альбомов:** загрузка через `fetch()`, проверка `response.ok`, обработка ошибок через `catch`, индикатор «Загрузка...».
2. **Информация об авторе:** при выборе альбома запрашивается пользователь по `userId` и выводятся его имя, username и email.
3. **Фотографии альбома:** запрос `?albumId=` (серверная фильтрация) и вывод миниатюр с подписями.
4. **Параллельные запросы:** информация об авторе и фото запрашиваются одновременно через `Promise.all()`.
5. **Обработка повторного выбора:** контейнеры очищаются через `innerHTML = ''` и сброс `display`, чтобы не было «хвостов».
6. **Сетка фотографий:** реализована через CSS Grid. Карточка содержит миниатюру (обернута в `<a target="_blank" rel="noopener noreferrer">`) и подпись, ограниченную двумя строками через `-webkit-line-clamp`.
7. **Счётчик фотографий:** рядом с именем автора выводится количество фото в альбоме.
8. **Дополнительно:** поиск альбома по названию (регистронезависимый) и сохранение последнего выбранного альбома в `localStorage`.

## Технологии
- HTML5
- CSS3 (CSS Grid, Flexbox)
- JavaScript (ES6+, Fetch API, Promise.all, DOM API, localStorage)
